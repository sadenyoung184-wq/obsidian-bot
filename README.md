# 🤖 دستیار هوشمند تلگرام + Obsidian

هر پیامی در تلگرام بفرستی — جزوه کلاس، قرار، ایده، کار، یادآوری، خاطره روزانه — با **Google Gemini** فهمیده می‌شود، در پوشه درستِ والت **Obsidian** ذخیره می‌شود، به نوت‌های قدیمی مرتبط **لینک** می‌شود (`[[wikilink]]`) و اگر لازم باشد سر ساعت در تلگرام **یادآوری** می‌فرستد.

## ✨ امکانات

| قابلیت | توضیح |
|---|---|
| 🧠 فهم هوشمند | Gemini پیام را دسته‌بندی می‌کند: کلاس، رویداد، مرور، تسک، یادآور، ایده، ژورنال، سوال |
| 🗂 حافظه کامل والت | ربات کل نوت‌هایت را می‌شناسد و با دانش واقعی‌ات تصمیم می‌گیرد (ایندکس خودکار) |

## 🎨 قشنگ‌سازی Obsidian (جدا از ربات)

1. تم **Minimal** + پلاگین **Style Settings** را نصب کن (رنگ و فونت بدون کد).
2. در Settings → Appearance → CSS snippets، اسنیپت **fa-rtl** را فعال کن (فایلش در `.obsidian/snippets/fa-rtl.css` هست و نوت‌های ربات خودکار راست‌چین‌اند).
3. پلاگین **Templater** را نصب کن و پوشه تمپلیت را `Templates` بگذار (۵ قالب آماده فارسی داخلش هست).
4. پلاگین **Dataview** را نصب کن و این را در یک نوت بگذار تا تسک‌های هفته را ببینی:
````markdown
```dataview
TABLE file.link AS "نوت", due AS "سررسید"
FROM "Tasks"
WHERE due >= date(today) AND due <= date(today) + dur(7 days)
SORT due ASC
```
````

## 🚀 راه‌اندازی (۵ دقیقه)

**۱. ساخت ربات تلگرام:** به [@BotFather](https://t.me/BotFather) پیام بده → `/newbot` → توکن را کپی کن.

**۲. گرفتن کلید رایگان Gemini:** به [aistudio.google.com/apikey](https://aistudio.google.com/apikey) برو و کلید بساز.

**۳. نصب و اجرا:**

```bash
cd obsidian-assistant-bot
pip install -r requirements.txt
cp .env.example .env
# حالا .env را باز کن و توکن‌ها و مسیر والت را وارد کن
python bot.py
```

**۴. پیدا کردن آیدی عددی تلگرام** (برای `ALLOWED_USER_IDS`): به [@userinfobot](https://t.me/userinfobot) پیام بده.

## ⚙️ تنظیمات (.env)

| متغیر | توضیح |
|---|---|
| `TELEGRAM_TOKEN` | توکن ربات از BotFather |
| `ALLOWED_USER_IDS` | آیدی‌های مجاز با کاما (خالی = همه) |
| `GEMINI_API_KEY` | کلید رایگان Gemini |
| `GEMINI_MODEL` | مدل (پیش‌فرض `gemini-3-flash-preview`) |
| `VAULT_PATH` | مسیر پوشه والت Obsidian |
| `TIMEZONE` | منطقه زمانی (پیش‌فرض `Asia/Tehran`) |
| `GIT_SYNC_ENABLED` | `true` فقط روی هاست ابری، روی لپ‌تاپ `false` |
| `GIT_REPO_URL` | آدرس ریپوی والت با توکن داخلش |
| `GIT_BRANCH` | شاخه گیت (پیش‌فرض `main`) |

## 📝 مثال

تو در تلگرام:
> یادم بنداز فردا ساعت ۸ صبح قرص بخورم

ربات:
- نوت در `Reminders/` می‌سازد
- سر ساعت در تلگرام پیام می‌فرستد ⏰
- در ترکر روزانه ثبت می‌کند
- اگر قبلاً درباره «قرص» یا «سلامتی» نوتی داشته باشی، به آن لینک می‌دهد

## 🏠 دو حالت اجرا (لپ‌تاپ یا هاست ابری رایگان)

**حالت ۱ — روی لپ‌تاپ خودت** (ساده، بدون سرور):
ربات روی لپ‌تاپ اجرا می‌شود و مستقیم داخل پوشه والت می‌نویسد.
عیب: وقتی لپ‌تاپ خاموش یا اسلیپ باشد، ربات جواب نمی‌دهد و یادآور سر ساعت نمی‌آید.
برای همیشه‌روشن بودن، ربات باید جایی روی اینترنت اجرا شود → حالت ۲.

```bash
nohup python bot.py > bot.log 2>&1 &
```

**حالت ۲ — روی هاست رایگان Render** (پیشنهاد، همیشه روشن):
ربات روی اینترنت ۲۴ساعته روشن است و نوت‌ها را با گیت به لپ‌تاپ می‌فرستد.

قدم ۱ — والت را روی گیت‌هاب بگذار:
1. در گیت‌هاب یک ریپوی **Private** بساز (مثلاً `my-vault`).
2. روی لپ‌تاپ، داخل پوشه والت:
```bash
git init -b main
git add -A && git commit -m "vault"
git remote add origin https://github.com/<username>/my-vault.git
git push -u origin main
```
3. یک توکن گیت‌هاب بساز: Settings → Developer settings → Personal access tokens → چک‌مارک `repo`.

قدم ۲ — ربات را روی Render بیاور بالا (رایگان):
1. پوشه `obsidian-assistant-bot` را در یک ریپوی گیت‌هاب جدا بگذار (مثلاً `obsidian-bot`).
2. به [render.com](https://render.com) برو → New → **Background Worker** → ریپوی ربات را انتخاب کن.
3. در Environment Variables این‌ها را بگذار (مقادیر را از `.env.example` ببین):
`TELEGRAM_TOKEN` ،`GEMINI_API_KEY` ،`ALLOWED_USER_IDS` و این سه‌تا برای سینک:
```
GIT_SYNC_ENABLED=true
GIT_REPO_URL=https://<username>:<token>@github.com/<username>/my-vault.git
VAULT_PATH=./MyVault
```
4. Deploy کن. از این به بعد ربات همیشه روشن است ✅

قدم ۳ — سینک خودکار در Obsidian لپ‌تاپ:
1. در Obsidian پلاگین **Obsidian Git** را نصب و فعال کن.
2. در تنظیماتش: `Pull` را روی `10 minutes` و `Push` را روی `20 minutes` بگذار.
3. تمام شد — نوت‌هایی که ربات می‌سازد خودکار روی لپ‌تاپ می‌آیند و ویرایش‌های تو هم به گیت‌هاب می‌رود.

> نکته: پلن رایگان Render اگر ۱۵ دقیقه ترافیکی نباشد سرویس را می‌خواباند؛ چون ربات تلگرام دائم polling می‌کند، عملاً بیدار می‌ماند. اگر خواستی ۱۰۰٪ مطمئن شوی، از cron-job.org یک پینگ هر ۱۰ دقیقه به آدرس سرویس بگذار.

یادآورها در فایل `Reminders/reminders.md` ذخیره‌اند و با ری‌استارت برمی‌گردند.
